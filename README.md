# 🚀 EDUMAP — Chat Application

**Platform:** Android (Flutter)  
**Version:** 1.0.0  
**Project Type:** Mobile Application  

---

## 📌 Overview

**EDUMAP** is a modern communication platform designed to enable seamless interaction between students and instructors. It supports both **one-to-one conversations** and **group communication**, enhanced with real-time location sharing and an AI-powered chatbot capable of acting on behalf of users.

---

## 🏗️ Backend Architecture

| Component                     | Role                                              |
|-------------------------------|---------------------------------------------------|
| **Supabase**                  | Authentication, storage, database, edge functions |
| **Firebase**                  | Firestore database                                |
| **Google Cloud**              | Integration layer with Firebase and Supabase      |
| **OpenStreetMap**             | Geolocation and map                               |
| **ZEGO Cloud**                | Voice and video call                              |
| **Stripe**                    | Payment gateway                                   |
| **SSLCommerz**                | Payment gateway                                   |
| **NVIDIA Nemotron 3 Super**   | AI Model                                          |
| **Local Notifications**       | Notification                                      |
